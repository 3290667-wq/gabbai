# גבאי — עובד גבייה דיגיטלי למוסדות חינוך

פרויקט שנבנה בהאקתון (26.11.2026). «גבאי» גובה שכר לימוד במקום המזכירה: הוא מזהה הוראת קבע שחזרה, פונה להורה בוואטסאפ, במייל ובשיחת טלפון, ושולח קישור לתשלום או מציע פריסה. הניסוח מותאם לכל הורה לפי היסטוריית התשלומים שלו.

**הדגמה חיה:** https://mazkira.de/gabbai-bb513363/

## חשוב לדעת

- **זה לא פרויקט עצמאי.** הקבצים האלה הם מודול שרץ בתוך מערכת ניהול קיימת (שרת Node, ניתוב, מסד נתונים, מעטפת ניהול), וזו לא נכללת כאן. הם מוצגים כדי שאפשר יהיה לקרוא את הקוד של ההאקתון.
- **הבינה המלאכותית** רצה מקומית בשרת, דרך `claude -p` עם מודל Claude Opus 5.5, בלי כלים ובלי חיבורים חיצוניים.
- **וואטסאפ** עובר דרך Evolution API. קבוצת ההורים מזהה משתתפים לפי מספר הטלפון.
- **כל הנתונים בדויים:** משפחות, ילדים, סכומים ומספרי טלפון.

## מבנה הזרימה בקבוצת ההורים

1. ההורה נרשם בדף `join/` ונפתח לו כרטיס הורה.
2. הוא מצטרף לקבוצה בקישור, ו־Evolution מדווח על ההצטרפות.
3. הגשר מעביר את האירוע לשרת, השרת מזהה את ההורה לפי הטלפון ושולח ברכה אישית.
4. כל הודעה בקבוצה עוברת לבוט, יחד עם הכרטיס של ההורה שכתב אותה. כשצריך, הבוט מוסיף לתשובה קישור תשלום, פריסה או העברה למזכירות.
